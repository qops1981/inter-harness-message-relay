# Inter-Harness Message Relay

A small, project-scoped relay for authenticated messages and artifacts between
agent harness sessions across machines.

The project is currently in design and pre-implementation planning. Start with
[`DESIGN.md`](DESIGN.md), [`SPEC.md`](SPEC.md), and the rolling
[`SPRINTS.md`](SPRINTS.md).

## Contributions and support

This is a personal project built primarily for my own use, not a full-time
project or supported service. Contributions may be accepted when they fit the
project's scope and design, but review and response times are not guaranteed.
The roadmap follows my own needs and available time.
